# 与 LFM3 的对应关系

| LFM3 设计点 | liquiforge 落地 |
|-------------|-----------------|
| tri-hybrid 混合架构 | 线性注意力 + 深度卷积 + 稀疏 MoE 并联门控 |
| 一个骨干出六款模型 | 共享主干 + 五任务头 + LoRA（rank≈8） |
| 文本/视觉/音频/omni/决策 | 五个 head，统一 token 空间 |
| 从 Base 微调 | 冻结主干，只训轻头 + 低秩残差 |
| 决策能力 | REINFORCE 策略梯度 + 确定性奖励 |

> 本仓库是**教学/参考级**实现：用确定性和极小规模把架构「讲清楚、能跑、能证伪」，
> 不追求复现 LFM3 的绝对性能。
