# 提示词 / 工作流模板

## 全模态理解提示词模板（可直接改）

```
你是一个 tri-hybrid 全模态模型。给定 <modality> 输入，请：
1) 提取关键结构（文本=主题/实体，视觉=对象/布局，音频=语音内容/情绪）
2) 用统一表示描述它，标注可跨模态对齐的要素
3) 如需决策，输出动作 + 置信度 + 依据

输入模态: {modality}
输入: {content}
约束: 表示必须与 text/vision/audio 共享同一语义空间
```

## 多任务微调工作流（recipe 模板见 recipes/）

```
1. 冻结主干 → 只训练任务头 → 基线（快、稳）
2. 加 LoRA rank=8 → 微调 → 对齐增量
3. 决策头接 RL，reward oracle 先行 → 可证伪
4. 每步跑 bench，确认对应指标单调 → 才算「真的在学」
```

## 评测提示词（omni 检索）

```
给定查询 <q> 与候选集 <C>，按语义相关度排序，返回 top-k 索引与理由。
```
