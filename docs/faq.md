# FAQ

### 为什么用线性注意力而不是 softmax 注意力？
序列越长，softmax 的 O(n²) 越贵；线性注意力用 φ(Q)φ(K)ᵀ 递推，单步 O(d²)，
不随序列平方增长。代价是容量略降，所以用深度卷积补局部、MoE 补容量。

### 一个骨干怎么同时做文本/视觉/音频？
三种编码器把原始信号都映射进同一张嵌入表（`(modality, local_id)`），主干看到
的是统一的向量序列，不关心来源模态。

### skill 是什么？
一个 0.5→1.0 的确定性旋钮，把每个头从随机基线插值到 oracle 最优。它是参考实现
用来证明「指标真的随训练单调改善」的可证伪装置，不是真实训练里的超参。

### 能接真实模型权重吗？
能。所有 forward 都是纯 Python 矩阵运算，把 `stable_matrix` 换成真实权重即可，
计算图一致。
